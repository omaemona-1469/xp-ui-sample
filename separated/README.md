# 分離版（モジュール化）

1ファイル完結版（`../index.html`）と同じ内容を、機能ごとに分けたものです。
見た目や動きは変わりません。コードを読む・直すときはこちらを使うと追いやすいです。

## 開き方

`index.html` をブラウザで開くだけです。ただし、ESモジュール（`type="module"`）を使っているため、**ファイルを直接ダブルクリックで開く方法はブラウザによって動かない場合があります**。Chrome では `file://` からのモジュール読み込みがブロックされるため、ローカルサーバー経由で開いてください。

```bash
cd separated
python3 -m http.server
# ブラウザで http://localhost:8000/ を開く
```

GitHub Pages などの HTTP 経由なら、そのまま開けます。

## 構成

```
separated/
├── index.html          # 画面の骨組み（HTML）。CSSとJSを読み込むだけ
├── style.css           # 見た目（CSS）
└── js/                 # 動き（JavaScript、ESモジュール）
    ├── main.js         # 入口。モジュールを読み込む順番と、またがる配線
    ├── state.js        # 共有状態（重なり順の番号、よく使う要素など）
    ├── windows.js      # ウィンドウとタスクバー
    ├── dialogs.js      # モーダルダイアログ
    ├── icons.js        # デスクトップアイコン（選択・移動・整列・範囲選択）
    ├── rename.js       # アイコンの名前変更
    ├── panels.js       # 見本ウィンドウの中身（メニュー・タブ・フォームなど）
    └── startmenu.js    # スタートメニューと時計
```

## 各モジュールの役割

| ファイル | 役割 | 使うもの |
|---|---|---|
| `js/main.js` | 入口。モジュールを読み込む順番を決め、アイコンやスタートメニューからウィンドウを開く配線と Esc キーの処理をする | windows / dialogs / panels / startmenu |
| `js/state.js` | 共有状態。デスクトップやタスクバーの要素、重なり順の番号（`nextZ()`）、ステータスバーの表示（`setStatus()`） | なし |
| `js/windows.js` | ウィンドウの表示・フォーカス、タスクバーのボタン、ドラッグ移動、リサイズ | state |
| `js/dialogs.js` | モーダルダイアログの表示・閉じる、ダイアログのドラッグ移動、ダイアログ用のタスクバーボタン | state |
| `js/icons.js` | アイコンの選択（Ctrl/Shift）、ドラッグでまとめて移動、等間隔整列、ゴムバンドでの範囲選択 | state / dialogs |
| `js/rename.js` | アイコンの名前変更（F2キー、名前をゆっくりクリック） | state / icons |
| `js/panels.js` | 見本ウィンドウの中身。メニュー、タブ、ボタン、フォーム、リスト、ツリー、プログレスバー、スライダー、カレンダー | state / windows / dialogs |
| `js/startmenu.js` | スタートメニューの開閉と各項目、タスクバーの時計 | state / windows / icons / dialogs |

## 読み方のヒント

- まず `js/main.js` を読むと、全体の流れ（何をどの順番で読み込むか）が分かります。
- 各モジュールの先頭に、そのファイルが何をするかと、どのモジュールに依存するかを書いています。
- モジュール間の矢印は一方向だけです（循環参照はありません）。たとえば `windows.js` は `state.js` だけを使い、`state.js` はほかのモジュールを使いません。
- 難しい処理には日本語のコメントを付けています。

## 1ファイル版との関係

`../index.html` は、この分離版とまったく同じ内容を1ファイルにまとめたものです。分離版を直したら、1ファイル版も同じ内容に直す必要があります（今は手作業で合わせています）。
