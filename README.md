# Windows XP風 UIサンプル

Windows XP（Lunaテーマ）風のデスクトップUIサンプルです。ボタン、フォーム、リスト、ツリー、タブ、プログレスバー、ダイアログ、メモ帳、タスクバー、スタートメニュー、時計まで、CSSとJavaScriptだけで再現しています。画像ファイルや外部リソースは使っていません。アイコンはインラインSVGです。

## 使い方

ブラウザで `index.html` を開くだけです。サーバーは不要です。

- `index.html` — 1ファイル完結版。CSSもJavaScriptも中に埋め込んであります。そのまま開けます。
- `separated/index.html` — 分離版。同じ内容を `index.html` / `style.css` / `script.js` に分けています。こちらもブラウザで開けます。

## 構成

```
.
├── index.html              # 1ファイル完結版（CSS・JS内包）
├── README.md               # このファイル
└── separated/
    ├── index.html          # 分離版のHTML
    ├── style.css           # 分離版のCSS
    └── script.js           # 分離版のJavaScript
```

1ファイル版と分離版は同じ内容です。見た目や動きは変わりません。編集しやすいのは分離版、配布しやすいのは1ファイル版です。

## できること

- ウィンドウ: ドラッグで移動、右下グリップや縁でサイズ変更、最小化・最大化・閉じる
- タスクバー: 開いているウィンドウが起動順に並ぶ。閉じると消え、最小化では残る
- スタートメニュー: 開く、時計表示
- デスクトップアイコン: ドラッグで移動、Ctrl/Cmd+クリックで複数選択、Shift+クリックで追加、空きドラッグで範囲選択、何もないところをクリックで選択解除
- アイコンの整列: スタートメニューから「アイコンを整列」で等間隔に並べ直す
- アイコンの名前変更: 選んでF2キー、または選んだアイコンの名前をゆっくりもう一度クリック。Enterで確定、Escで取消
- ダイアログ: 情報・確認・警告・エラー。タイトルバーをドラッグで移動できる。ごみ箱のダイアログ表示中も他のウィンドウを開ける
- メモ帳: 文字入力ができる
- UIコンポーネント見本: ボタン、フォーム、チェックボックス、ラジオボタン、タブ、リスト、ツリー、プログレスバー、スライダーなど
- ダイアログの見本: 各種ダイアログの表示例

## 注意

- 幅760px以下ではモバイル用の表示になり、ウィンドウのドラッグやリサイズ、アイコンのドラッグは無効になります。アイコンは横並びになります。
- このサンプルは見本です。実際のWindows XPではありません。
